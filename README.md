# Adam ReFactored

**AI systems, adversarially tested.**

Founder, Lotus Oak.

I build AI into systems that already matter: money, machines, and the work of
running them. Then I try hard to break what I built before anyone relies on it.

### What I work on

- **AI integration**: agents wired into real systems through typed tools, with
  humans holding the keys.
- **Finance**: software that shows a financial life at a glance, built on audit
  trails you can verify rather than trust.
- **Industrial & robotics**: I grew up around industrial machinery. The machines
  that already run the world deserve an intelligence layer, not a replacement.
- **Games as proving grounds**: an agent that can run a colony under scarcity,
  with raiders at the door, has earned a look at harder problems.

### How I work

- **Refactor, don't rewrite.** Change the structure; keep the behavior that works.
- **Adversarial by default.** The systems that matter get attacked by me before
  they're trusted by anyone.
- **Gates before the mistake.** In anything that publishes or moves money, a person
  approves the irreversible step.
- **Show the evidence.** A claim without a test is a hope.
